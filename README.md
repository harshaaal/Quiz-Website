# 🧠 Quiz Website

A simple, interactive, and responsive **Quiz Website** built using **HTML, CSS, and JavaScript**. The application allows users to answer multiple-choice questions, manage their time, navigate through questions, and view their final score.

---

## 📌 Overview

The **Quiz Website** is a frontend web application developed to provide a simple and engaging online quiz experience.

The project demonstrates practical implementation of **JavaScript logic, DOM manipulation, event handling, timers, question management, and score calculation** using only core web technologies.

---

## ✨ Features

* 📝 Multiple-choice quiz questions
* ⏱️ Timed quiz experience
* ➡️ Next question functionality
* 📊 Current question and total question count
* 🎯 Automatic score calculation
* 🏆 Final result display
* 📱 Responsive and user-friendly interface
* ⚡ Built entirely with HTML, CSS, and JavaScript
* 🚫 No external frameworks or libraries required

---

## 🚀 Getting Started

### Prerequisites

No additional software, frameworks, or dependencies are required.

You only need a modern web browser such as:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox

### Installation

1. Clone the repository:

```bash
git clone https://github.com/harshaaal/Quiz-Website.git
```

2. Navigate to the project directory:

```bash
cd Quiz-Website
```

3. Open `index.html` in your web browser.

The quiz is now ready to use.

---

## 🎮 How It Works

1. The quiz loads the available questions.
2. The user selects an answer from the given options.
3. The user proceeds to the next question.
4. The countdown timer tracks the available time.
5. The quiz automatically finishes when all questions are answered or the timer expires.
6. The final score is calculated and displayed.
