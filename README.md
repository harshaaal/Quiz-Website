# 🧠 Quiz Website

A simple and interactive **Quiz Website** built using **HTML, CSS, and JavaScript**.
The website allows users to answer multiple-choice questions and view their quiz results.

## 🚀 Features

* 📝 Multiple-choice quiz questions
* ⏱️ Timed quiz experience
* ➡️ Next question functionality
* 📊 Question count display
* 🎯 Score/result display
* 📱 Simple and responsive user interface
* ⚡ Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

* **HTML5** — Structure of the website
* **CSS3** — Styling and layout
* **JavaScript** — Quiz logic, questions, timer, and result handling

## 📂 Project Structure

```text
Quiz-Website/
│
├── index.html
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start the quiz and answer the questions.

## 🎯 Purpose

This project was created to practice **frontend web development**, especially working with HTML, CSS, JavaScript, DOM manipulation, and basic JavaScript logic.
